# FleetVision → Limitless-Inspired Frontend Migration

## Decisions (faithful to the task's "primary reference = Limitless default layout")
- **Default color mode → Light.** Light top navbar, `#f5f5f5` content, white cards = the recognizable Limitless Layout 1. Dark mode stays fully supported and is restyled to the same system (toggle persists). Easily flipped back if desired.
- **Always-dark sidebar** (`#263238` slate) in both modes = the signature Limitless silhouette. Navbar/content adapt to the active mode; the sidebar stays dark.
- **Palette:** adopt Limitless's Material-derived system colors (primary `#2196F3`, success `#4CAF50`, danger `#F44336`, warning `#FF5722` deep-orange, info `#00BCD4`) so the UI reads "Limitless." FleetVision identity is preserved via the **brand mark** (keep the blue→indigo gradient + truck logo + "FleetVision" wordmark) and domain UX — *not* by recoloring system tokens.
- **Preserve everything functional:** all routes, API/state (React Query, Zustand, socket/WebRTC), map/video/trip-playback logic, i18n keys, and tests. This is a UI/design-layer transformation.

## Architecture context (verified)
- React 19 + MUI 6 + Vite + TS. Emotion cache w/ `stylis-plugin-rtl` (per-direction). Theme = `palette.ts` + `theme.ts`(light) + `dark.theme.ts`(dark) + `ThemeRegistry.tsx` (mode + direction) + `rtl.ts`. Shell = `AppLayout` (permanent Drawer 240/72 + AppBar 56 + content `p:3` + `<Outlet>`) and `AuthLayout` (split panel). i18n `en/fa` `common.json` with `nav.*`/`common.*`. Existing reusable pieces: `WidgetCard`, `StatCard`, `KpiCard`, `ErrorState`, `UpcomingFeature`, `LanguageSwitcher`.

## Phase 1 — Design tokens & theme foundation
**Files:** `src/theme/palette.ts`, `src/theme/theme.ts`, `src/theme/dark.theme.ts`, `src/theme/ThemeRegistry.tsx`, `src/styles/global.css`, `index.html`
- `palette.ts`: replace with Limitless Material palette + neutrals (`#333` text, `#777` muted, `#ddd`/`#eee` borders, `#B7B7B7` table-head), keep `mapAccents`; add `sidebar` token (`#263238` + `#2A353D` group-header strip + `rgba(255,255,255,0.08)` borders), keep `shadows` but make cards near-flat (`0 1px 2px rgba(0,0,0,0.05)`).
- Typography → **Roboto** base, **13px** body (0.8125rem), heading weights ~500–600, h1–h6 ≈ 25/23/21/19/17/15px. Add **Vazirmatn** (Persian) for `fa` via Google Fonts in `index.html` + font-family stack branch on `[dir="rtl"]` in `global.css`.
- `shape.borderRadius` → **3px** (cards/inputs/buttons/menus); keep `100px` for pills/badges via component overrides.
- `ThemeRegistry.tsx`: change `getInitialMode` default `dark` → `light`; keep toggle + persistence + RTL direction sync.
- `global.css`: scrollbars/selection tuned to new palette; keep keyframes.
- Component overrides in both themes: `MuiCard` (white light / `#1E272E` dark, 3px radius, 1px border `#eee`/`rgba(255,255,255,0.08)`, flat shadow, 20px padding), `MuiButton` (3px radius, weights 500–600, contained `#2196F3`, raised shadow opt-in), `MuiTable*` (header `#fafafa` light, bottom border `#B7B7B7`, row hover `rgba(0,0,0,0.05)`), `MuiChip`/`badge` (pill 100px + flat tinted variants), `MuiTab` (underline, `#777` inactive), `MuiOutlinedInput`/`Select` (3px radius, `#ced4da` border), `MuiDialog`/`Drawer` (3px radius), `MuiListItemButton` (sidebar dark styling), pagination styling.

## Phase 2 — Shared UI primitives (`src/components/ui/`, new)
Create a thin design-system layer (no duplicate concepts; adapt existing where present):
- `Panel.tsx` — Limitless card w/ optional header (title + icon + actions + `SectionLabel`) and divider; supersedes `WidgetCard` styling (keep `WidgetCard` API, restyle internally).
- `PageHeader.tsx` — page title + subtitle + optional actions + breadcrumb slot.
- `Breadcrumb.tsx` — Limitless breadcrumb (home + trail, `/` separator, RTL-aware).
- `SectionLabel.tsx` — uppercase 12px tracked group label (sidebar + card groups).
- `StatusBadge.tsx` — unified pill badge w/ severity/status color map (used by trips/alarms/assets/admin).
- `DataTable.tsx` — one consistent table pattern (header, sticky head, hover, zebra-optional, action-column, loading skeleton, empty/error states) to replace ad-hoc tables.
- `Toolbar.tsx` — filter/search row wrapper.
- `EmptyState.tsx` / reuse `ErrorState`, `UpcomingFeature` (restyled).

**Files:** `src/layouts/AppLayout.tsx`, `src/layouts/AuthLayout.tsx`, `src/components/LanguageSwitcher.tsx`, `src/components/LoadingSpinner.tsx`, new `src/components/shell/Sidebar.tsx`, `Topbar.tsx`, `nav.config.tsx`
- `nav.config.tsx`: grouped nav (Dashboard; **TRACKING** Map/Trips; **VIDEO** Video Wall; **OPERATIONS** Alarms/Commands/Geofences; **ASSETS** Assets; **REPORTING** Reports; **MAINTENANCE** Maintenance; **ADMINISTRATION** Admin) — only existing routes, each w/ icon + optional permission; `/vehicles`,`/drivers` already redirect to `/assets` so dropped from sidebar.
- `Sidebar.tsx`: dark slate permanent drawer, **270px / 56px** collapse, brand mark at top, `SectionLabel` group headers on darker strip, nav items (icon+label, active = left accent bar + tinted bg, hover bg), collapse toggle, **mobile off-canvas** below 992px (lg).
- `Topbar.tsx`: light navbar ~50px, hamburger (mobile/collapse), pill search, notifications bell w/ count badge → `/alarms`, help, theme toggle, `LanguageSwitcher`, user dropdown (profile/logout). Logo lives in sidebar (Limitless L1).
- `AppLayout.tsx`: compose Sidebar + Topbar + content (`#f5f5f5`, 20px padding) with `<Outlet>`; add a content `<PageHeader>`/breadcrumb context driven by route; keep full-bleed map/video pages working (their `m:-3` → neutralize to new padding via a token).
- `AuthLayout.tsx`: restyle to Limitless auth language (lighter, 3px cards, branded side panel kept but tonally adjusted); RTL-safe.
- RBAC: nav items with a `permission` hide when absent from `useAuth().user.permissions` (non-breaking; items without a permission always show — preserves today's behavior).
