# Sprint FE-3 — Fleet Dashboard

پیاده‌سازی کامل صفحه `/dashboard` طبق `docs/specs/UI_UX_Design.md §1` (Fleet Dashboard) با ۷ منطقه ویجت. تمام داده‌ها mock هستند (هیچ backend endpoint وجود ندارد) و TanStack Query stub می‌شود تا در آینده با API واقعی جایگزین شود — همان الگوی صادقانه‌ی auth stubs.

## انتخاب‌های تأیید‌شده
- **چارت:** Recharts
- **نقشه:** MapLibre GL + کاشی رایگان OSM
- **آب‌وهوا:** widget مستقل با mock
- **داده:** mock ثابت + TanStack Query

## معماری داده (الگوی صادقانه، مشابه auth)

### فایل‌های جدید
```
src/api/fleet.api.ts          # query hooks + mapXxxResponse (همان الگوی auth.api)
src/types/fleet.types.ts      # تایپ‌های FleetStats, Alert, Vehicle, Weather, …
src/mock/fleet-data.ts        # داده ثابت مرجع (از §1.3 wireframe: Active=312, Driving=184, …)
src/api/query-keys.ts         # query-key factory (وجود ندارد؛ ایجاد می‌شود)
```

`fleet.api.ts` به جای `NotImplementedError`، مستقیماً mock را برمی‌گرداند چون UI باید قابل‌دمو باشد. کامنت می‌گذارم که با فرود endpoint واقعی، فقط `apiGet` جایگزین شود. `useFleetStats()`, `useActiveAlerts()`, `useWeather()` hooks از TanStack Query با staleTime 30s.

## لایه ویجت‌ها — ۷ منطقه طبق §1.3 wireframe

### ۱. ردیف Stat Cards (بالا) — «Vehicle Status»
۵ کارت: Active / Driving / Idle / Offline / Alerts با مقدار، delta vs دیروز، sparkline. کلیک → `/map?status=`. کامپوننت جدید `StatCard` (طبق §0.5: value, delta, sparkline, drilldown).

### ۲. Fleet Activity (۲۴h) — «Statistics»
چارت stacked area (driving/idle/stopped) با Recharts `<AreaChart>`. selector زمان (Today/7d/30d)؛ badge "Live" فقط روی Today. legend دوگانه‌ی filter.

### ۳. Active Alerts — «Alarms»
پنل زنده، severity-sorted (CRITICAL → warning). هر ردیف: آیکون severity، نوع (OVERSPEED/IDLE/GEOFENCE/FCW)، خودرو، زمان. فوتر «View all →». رنگ از `status.red/amber`.

### ۴. Vehicles Needing Attention
لیست رتبه‌بندی‌شده ترکیبی (DTC، behavior، AI، device-health). آیکون دسته‌بندی + توضیح کوتاه.

### ۵. Fleet Utilization
donut (Recharts `<PieChart>`) + نوارهای افقی: Driving 59% / Idle 13% / Stopped 19% / Offline 9%. عدد بزرگ 73% در مرکز.

### ۶. Map Preview — «Map»
MapLibre GL map کوچک با مارکرهای vehicle واقعی (رنگ = status طبق `mapAccents`: cyan=active, yellow=idle, rose=overspeed, slate=offline). خوشه‌بندی ساده. با فرود اسپرینت Map کامل، به آن متصل می‌شود.

### ۷. Weather — «Weather» (طبق خواست کاربر، widget مستقل)
کارت آب‌وهوای فعلی (دما، آیکون شرایط، رطوبت، باد) + پیش‌بینی ۳ روزه. داده mock.

## رعایت الگوهای موجود (از کاوش)

- `useTranslation()` با کلیدهای نقطه‌دار.
- loading = skeleton (نه spinner) طبق §0.6.
- empty state = illustration + CTA طبق §8.11.
