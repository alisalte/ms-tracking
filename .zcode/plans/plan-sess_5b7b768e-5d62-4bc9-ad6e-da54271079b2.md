## Step 3: Theme System (MUI)
**Implement `src/theme/`** following the FleetVision Design System (§0.2-0.4):

**Light theme palette:**
- Primary: `#2563EB` (deep blue) / hover `#1D4ED8` / pressed `#1E40AF`
- Neutral scale: `#FFFFFF` → `#0F172A` mapped to MUI grey tokens
- Status: success `#16A34A`, warning `#F59E0B`, error `#DC2626`, info `#2563EB`
- Typography: Inter font family, JetBrains Mono for data
- Border radius: 6px (buttons), 8px (cards)
- 8-point spacing grid

**Dark theme:**
- Map dashboard defaults to dark; others follow OS `prefers-color-scheme`
- Dark base: `#0F172A` background, `#F8FAFC` text (inverted neutral scale)

**ThemeRegistry component:**
- `<CssBaseline />` + `<ThemeProvider>` + `<StyledEngineProvider>`
- Detects OS preference, stores user override in localStorage
- Exposes `useThemeContext()` hook for toggling

## Step 5: Authentication (Zustand + API)
**Implement `src/auth/` + `src/api/`:**

### Token Storage
- Access token + refresh token stored in `localStorage` (keyed by `fleetvision_tokens`)
- `X-Tenant-Id` header from localStorage or login form

### Zustand Auth Store (`auth.store.ts`)
State:
- `accessToken: string | null`
- `refreshToken: string | null`
- `user: { id, email, tenantId, roles, permissions } | null`
- `isAuthenticated: boolean`
- `isLoading: boolean`

Actions:
- `login(email, password)` → POST `/api/v1/auth/login` with `X-Tenant-Id` header
- `refreshTokens()` → POST `/api/v1/auth/refresh`
- `logout()` → POST `/api/v1/auth/logout`, clear tokens
- `fetchUser()` → GET `/api/v1/auth/me`
- `setTokens(access, refresh)` → internal setter

### Axios Client (`api/client.ts`)
- Base URL from `import.meta.env.VITE_API_BASE_URL` (default: `/api/v1`)
- Request interceptor: attach `Authorization: Bearer <token>` + `X-Tenant-Id`
- Response interceptor: on 401, attempt token refresh; retry original request; if refresh fails, logout and redirect to `/login`
- Response envelope unwrap: `{ data: T }` extraction helper

### Auth Guard (`auth.guard.tsx`)
- Checks `isAuthenticated` from Zustand store
- If not authenticated: `Navigate` to `/login?redirect={currentPath}`
- If loading: skeleton placeholder
- Wraps `<Outlet />` in `<AppLayout>`

### LoginPage
- MUI `Card` centered on screen (AuthLayout)
- Email input + Password input + Tenant ID input
- Submit calls `authStore.login()`
- Error display with MUI `Alert`
- Redirects to `/dashboard` on success
- Loading state on submit button

## Step 7: TanStack Query Setup
**Implement query client in `App.tsx`:**

- `QueryClientProvider` wraps the entire app
- Default options: `staleTime: 30_000`, `retry: 1`, `refetchOnWindowFocus: true`
- Query keys convention: `['auth', 'me']`, `['vehicles', { fleetId, status }]`, etc.
- Export `useQuery` and `useMutation` from a `src/api/query-client.ts` for consistent usage
