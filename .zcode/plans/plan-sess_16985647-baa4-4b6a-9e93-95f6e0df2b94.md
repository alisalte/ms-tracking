# Sprint FE-5 — Trips (List + Trip Replay, Timeline, Speed Graph, Stops, Idle)

Two new screens: a **Trips list** (`/trips`) and a **Trip detail** (`/trips/:id`) with GPS replay. Net-new UI — `UI_UX_Design.md` has no Trips screen — so I design from the domain model (`Trip-Route-Management.md`) and the documented GPS Engine contracts (`GPSEngine.md` §4–§5: trip FSM, stop ≥5 min at POI, idle = ignition ON + speed ≤1 km/h for ≥3 min; `07_GPS_Engine.md` §8 replay endpoint). All data is mock-backed via the same TanStack Query honest-stub pattern; swap mock → `apiGet`/replay endpoint when backends land.

## Confirmed decisions
- **Replay map:** a dedicated `TripReplayMap` component drawing the trip polyline (`mapAccents.selectedRoute` green) with an animated vehicle marker + stop/idle markers. FleetMap has no polyline support, so a focused component is cleaner.
- **Structure:** Trips list page (`/trips`) + Trip detail page (`/trips/:id`).
- **Playback:** full transport — play/pause, seekable scrubber, 1×/2×/4× speed, and event markers (stops/idle/overspeed) on the timeline that jump playback when clicked (adapted from the §3.7 video transport pattern).

## New / changed files

**Types** (`src/types/fleet.types.ts` — add a new `trips` section)
- `Trip`: `id, vehicleId, vehicleLabel, driverId?, driver?, status ('completed'|'in_progress'|'planned'|'cancelled'), originLabel, destinationLabel, startTime (ISO), endTime?, distanceKm, durationMin, maxSpeed, avgSpeed, stopCount, idleMin, fuelL?`. (Blends the operational Trip with the GPS trip-boundary metrics `maxSpeed/stopCount`.)
- `TripWaypoint`: `{ ts (ISO), lat, lng, speed (km/h), heading }` — one replay position sample.
- `TripEvent`: `{ id, ts, type ('stop'|'idle'|'overspeed'|'geofence'), lat, lng, label, durationMin? }` — markers on the timeline/map.
- `TripDetail extends Trip`: `waypoints: TripWaypoint[]`, `events: TripEvent[]`.

**Mock data** (`src/mock/fleet-data.ts` — add)
- `mockTrips: Trip[]` (~12 trips over the last few days, varied vehicles/drivers/statuses/dates) — deterministic, drawn from the existing `mockMapVehicles` so labels/drivers are consistent.
- `mockTripDetail(id): TripDetail` (factory, like `mockVehicleDetail`): generates a believable ~40–80-point waypoint track between two Tehran points with realistic speed variation (accelerate/cruise/decelerate, idle plateaus at 0, overspeed spikes), and derives `events` (stops where speed=0 ≥5 min, idle where speed≤1 ≥3 min with ignition, overspeed where speed>limit) directly from the waypoints so the timeline/speed-graph/markers all agree.

**Data layer** (`src/api/fleet.api.ts`, `src/api/query-keys.ts` — add)
- `queryKeys.trips`: `{ all, list, detail(id), active }`.
- `useTrips(filters)` + `useTripDetail(id)` + `useActiveTrips()` — mock fetchers with documented future endpoints (`GET /api/v1/trips`, `GET /api/v1/trips/{id}` + replay `GET /api/v1/tracking/vehicles/{vehicleId}/replay`).

**Replay map** (`src/components/trips/TripReplayMap.tsx`)
- Dedicated MapLibre map: same OSM init pattern as FleetMap, but adds a GeoJSON `route` line source+layer (green `mapAccents.selectedRoute`, dashed) from `waypoints`, stop markers (`markerDataUrl` amber) + idle markers at event lat/lng, and an animated vehicle marker that follows the current replay index (heading-rotated arrow). Fit-bounds to the track on load.

**Playback + timeline** (`src/components/trips/`)
- `useTripPlayback.ts` — hook owning replay state: `isPlaying, index, speed (1|2|4), play(), pause(), seek(i), setSpeed()`. Advances `index` via `setInterval` scaled by `speed`; clamps at the last waypoint; pauses at the end.
- `TripTimeline.tsx` — the seekable scrubber bar with play/pause, speed buttons (1×/2×/4×), a draggable playhead, and event markers (colored ticks for stop/idle/overspeed) that seek when clicked.
- `SpeedGraph.tsx` — Recharts `LineChart` of `speed` over time with `ReferenceLine` for the speed limit + `ReferenceDot`s for events, a custom Tooltip (speed + time), and a highlighted playhead following the current replay index.
- `TripSummary.tsx` — the stat row (distance, duration, max/avg speed, stops, idle time) using `StatCard`-style tiles.

**Pages**
- `src/pages/TripsPage.tsx` (`/trips`) — filterable table: vehicle/driver/status filters + date, columns (trip id, vehicle, driver, route, date, distance, duration, status). Row click → `/trips/:id`. Uses `useTrips`.
- `src/pages/TripDetailPage.tsx` (`/trips/:id`) — `useParams` → `useTripDetail`; layout: header (vehicle + route + date + status), `TripSummary`, then a 2-col grid: `TripReplayMap` (left, full-bleed-ish) + `SpeedGraph` (right top) and `TripTimeline` (full width below) + an events list (stops/idle/overspeed).

**Router** (`src/router/index.tsx`) — add `{ path: '/trips', element: <TripsPage/> }` and `{ path: '/trips/:id', element: <TripDetailPage/> }` under the AppLayout children.

**i18n** — add a top-level `trips.*` section to both `en/common.json` and `fa/common.json`: `title, subtitle, list.{columns…, count, noResults, filters…}, detail.{back, route, summary labels}, summary.{distance, duration, maxSpeed, avgSpeed, stops, idleTime, fuel}, replay.{play, pause, speed, timeline, legend, live}, timeline.{play, pause, speed, events, stop, idle, overspeed}, speed.{axis, limit}, events.{stop, idle, overspeed, geofence, title, none}, status.{completed, in_progress, planned, cancelled}`, with Farsi translations + RTL support.

**Tests** (`src/__tests__/trips.spec.tsx`) — reuse the harness (maplibre-gl + supercluster mocks, providers, i18n, MemoryRouter). Assert: TripsPage renders the list + filters rows by vehicle/status; TripDetailPage renders summary + speed graph + timeline; playback play/pause advances the playhead; event markers render.
