# Risks

| Risk | Impact | Mitigation |
|------|--------|------------|
| Treating vision features as “done” (✅) | False delivery claims; wasted sales/demo trust | Scorecard in this analysis; update roadmap honestly |
| Driver score without assignment history | Wrong attribution; coaching disputes | Q0 assignment history first |
| Predictive before CMMS | “Predictive” with nowhere to act | Split F-06a / F-06b |
| Fuel without sensors/card data | Empty analytics | Gate F-03 on data-source decision |
| Custom Report Builder too early | Large UX cost, low adoption | Schedule existing reports first |
| Digital Twin undefined | Endless scope | Require written twin definition or defer |
| Assistant without guardrails | Wrong commands / data leak | RBAC + allowlisted tools + audit |
| Optimization without constraints | Useless routes | Collect stop/capacity model first |
| Cloud AI video before device capture reliability | Double spend | Harden MD300 evidence path first |
| Parallelizing all eleven | Context thrash | Stick to Q1 sequence |

## Non-goals for this analysis

- Implementing any of the eleven features
- Changing vision document phase numbers without ARB
- Committing ML accuracy targets without datasets
