# Business goals

| ID | Goal | Measurable outcome |
|----|------|--------------------|
| BG-F01 | See fuel activity per vehicle | List of fuel events (refill / drop / level) for a date range |
| BG-F02 | Understand consumption | Summary: liters consumed / distance / L per 100 km (when data allows) |
| BG-F03 | Spot anomalies | Rapid drop / theft-like events surfaced in UI and/or linked to alarms |
| BG-F04 | Report export | CSV (or report section) for fuel summary by vehicle |
| BG-F05 | Stay scoped | No fuel-card provider / station CRM in v1 |
| BG-F06 | Foundation | Durable events usable later for cards, billing, ML |
