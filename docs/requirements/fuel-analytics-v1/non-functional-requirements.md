# Non-functional requirements

| ID | Requirement |
|----|-------------|
| NFR-01 | Tenant isolation on every read/write. |
| NFR-02 | EN + FA i18n for Fuel UI. |
| NFR-03 | Event list paginated; summaries bounded by date range (max window documented, e.g. 90 days). |
| NFR-04 | Permission-gated APIs; UI gates UX only. |
| NFR-05 | Fuel pipeline must not block tracking/alarms if fuel service is down. |
| NFR-06 | Store volumes in liters (canonical); display may localize units later. |
| NFR-07 | Graceful empty states when no sensor / no events. |
