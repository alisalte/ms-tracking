# Use cases

## UC-1 Refresh alarm event settings

Operator opens device Parameter → Alarm, clicks Refresh, sees event rows with head + delay from device.

## UC-2 Edit Link Sett for Overspeed

Operator opens Overspeed → Link Sett, sets phones SMS, enables GPRS, sets delay 10 s, enables CH1 Recording, clicks Setting, sees ACK success.

## UC-3 Device offline

Operator tries Setting while device unreachable; UI shows failure; values not shown as saved.

## UC-4 (optional) Full Parameter browse

If scoped: operator navigates Parameter sections equivalent to the vendor app and edits supported fields.
