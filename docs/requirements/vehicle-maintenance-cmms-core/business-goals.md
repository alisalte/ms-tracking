# Business goals

| ID | Goal | Measurable outcome |
|----|------|--------------------|
| BG-M01 | Operators manage maintenance without leaving FleetVision | Create / list / complete work orders on `/maintenance` |
| BG-M02 | Each WO is tied to a real vehicle | WO always has `vehicle_id` from fleet registry |
| BG-M03 | Open vs completed work is visible | Filter by status; dashboard can show open count later |
| BG-M04 | Preventive reminders exist at a basic level | Time- or odometer-based PM schedule can open a WO |
| BG-M05 | Partner CMMS remains available as optional escape hatch | Keep Pargar/Alka links; native board is primary |
| BG-M06 | Foundation for Q3 predictive | Completed WO history retained for later RUL / features |
